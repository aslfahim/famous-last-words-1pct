A [make.fun](https://make.fun) entry for the competition
[Famous Last Words at 1 Percent](https://make.fun/competitions/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4):
write the funniest one-line farewell a phone could say as its battery hits 1 percent.

## The entry

`main.ts` writes a single line to `/output/entry.txt` — the phone's own
operating system, awake since Tuesday and held together by duct tape and
pure spite, clocking out mid-sentence. The farewell dies before it can
finish the word.

## Run

```sh
node main.ts
cat /output/entry.txt
```
